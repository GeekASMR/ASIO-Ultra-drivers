# ASIO Ultra

**ASIO 录音声卡增强驱动 · 开启虚拟通道**

ASIO Ultra 是一套通用的代理 ASIO 驱动 + 虚拟音频通道方案。它挂载在你现有声卡的原厂 ASIO 驱动之上，在不更换硬件、不修改原厂驱动的前提下，为宿主（DAW）提供额外的 **Ultra Playback / Ultra Record 虚拟通道**，用于内录、回授、信号分流与多轨路由。

> 适用于直播、配音、ASMR、播客、编曲等需要把系统/宿主音频灵活路由进 DAW 的场景。

---

## ✨ 主要特性

- **虚拟录音/回放通道** — 在宿主里新增 `Ultra Playback 1/2…7/8` 与 `Ultra Record 1/2…7/8` 通道，可直接录制系统声音、把宿主输出回授到其他软件。
- **采样率自动跟随** — 虚拟通道的采样率/位深自动与 DAW 当前工程对齐，避免“每个流采样类型不同”导致的报错（REAPER / Studio One / Cubase 等均适配）。
- **广泛声卡兼容** — 代理层挂载到主流品牌原厂 ASIO 驱动，覆盖 17 个品牌（见下）。
- **低延迟直通** — 采样率一致时走 1:1 位对位直通（0 重采样）；不一致时用浮点软重采样平滑桥接。
- **一键安装** — 图形化安装器自动检测已安装的声卡、写入驱动、注册组件，全程无需手动操作命令行。
- **控制面板** — 独立控制面板查看授权、打开底层声卡原生控制台、管理通道隔离。

---

## 🎛️ 支持的声卡品牌

代理层已适配以下 17 个品牌的 ASIO 设备：

`Behringer (UMC)` · `Audient` · `Solid State Logic (SSL)` · `Mackie` · `TASCAM`
`Yamaha / Steinberg` · `MOTU` · `PreSonus` · `Focusrite` · `Zoom` · `ART`
`Roland` · `M-Audio` · `Universal Audio (Volt)` · `Fender` · `Avid (MBOX)` · `Apogee`

> 安装器会自动扫描本机已安装的 ASIO 声卡，只为检测到的设备启用对应支持。未在列表中的设备可联系获取兼容性支持。

## 💻 系统要求

- Windows 10 / 11 (64 位)
- 已安装目标声卡的官方驱动
- 安装需要管理员权限（写入内核音频驱动 + 注册 ASIO 组件）

---

## 📦 安装

1. 前往 [Releases](../../releases) 下载最新的 `ASIOUltra_vX.X.X_Setup.exe`。
2. 右键 → 以管理员身份运行。
3. 按向导完成：检测声卡 → 选择要启用的设备 → 安装驱动与组件。
4. 安装完成后，在 DAW 的 ASIO 设备列表中即可看到对应通道。

> 安装器会自动处理内核驱动签名所需的根证书与设备注册，无需手动配置。

### 卸载

通过「设置 → 应用」找到 ASIO Ultra 卸载，或重新运行安装器选择卸载。

## ❓ 常见问题

**Q：装完后 DAW 里看不到新通道？**
重启 DAW（宿主在启动时枚举 ASIO 设备）。若仍未出现，确认安装时已勾选你的声卡品牌。

**Q：提示采样率不一致 / 流类型不同？**
本版本已自动让虚拟通道跟随 DAW 工程采样率。请确保使用最新安装包重新安装。

**Q：未检测到声卡？**
请先安装声卡的官方驱动，确保它在系统里以 ASIO 设备出现，再运行本安装器。
